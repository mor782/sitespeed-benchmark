# ⚡ E-Commerce Performance Benchmark

A web performance benchmarking tool that helps you compare the performance of two or more websites to identify areas for improvement.

## 📊 Key Metrics Tracked
* ⚡ **LCP (Largest Contentful Paint):** Measures loading performance and perceived load speed.
* ⏱️ **TTFB (Time to First Byte):** Measures how quickly the server responds to a request.
* 📦 **Page Weight:** Measures the total size of the webpage resources.
